# Contributing to OmniCAD-Skill

Welcome! Contributions to CAD recipes, documentation and verification are appreciated.

1. Open an issue describing the intended change.
2. Use synthetic inputs; never upload confidential drawings or customer data.
3. Run `python -m unittest discover -s tests -v` and report the results.
4. For native AutoCAD changes, include version, save/reopen evidence and any manual checks still pending.
5. Submit a focused pull request. Do not claim unsupported engineering compliance.

See [SKILL.md](SKILL.md) and [validation records](references/validation.md).

中文：请使用脱敏合成案例、运行回归测试、记录原生 CAD 版本与未完成的验收项。
